# Day 2, Uncancelled — AIXP Virtual Campus

Landing page for the AIXP virtual campus day (11 November 2026): registration, 5-minute stage slots and matchmaking.

- Source in `src/` (Vite + React + Tailwind). Build with `npm install && npm run build`.
- The built site is in `docs/` and is served by GitHub Pages at https://day2-regained.aixp.io
- Data lives in the event backend (Lovable Cloud); the browser only uses the public key and RPCs.
